# 重賞ボード（毎週自動生成）

JRA・スポーツナビから登録馬を取り込み、カード型HTMLを `docs/` に作ります。GitHub Actions が毎週（火・木・金の朝6時）自動で実行します。

## 初回セットアップ（10分）
1. GitHubで新しいリポジトリを作り、このフォルダの中身をすべてアップロードする。
2. Settings → Pages → Branch を `main`、フォルダを `/docs` にして保存する。
3. Actions タブ → `weekly` → Run workflow で1回手動実行する。
4. 数分後、`https://（ユーザー名）.github.io/（リポジトリ名）/` に公開される。

## 毎週やること（1分）
`races.json` に、その週の重賞を1件足します（slug・date・title・meta・各URL）。
- `sportsnavi`：スポーツナビの特別登録ページのURL（レース番号入り）
- `jra_prerating` `jra_rank_news` `jra_analysis`：GⅠのときだけ。重賞（GⅡ・GⅢ）は書かなくてOK
- `scratched`（回避馬）と `g1_winners`（GⅠ勝ち馬）は手入力です

## 制限
- 競馬ラボは自動アクセスを拒否しているため使っていません。JRAの特別登録PDFは文字データがなく読めません。
- 開催済みのレースは再取得せず、最後の状態を残します。
- 取得元のページ構造が変わると取り込みに失敗します。その場合は前回のページが残ります。
- 各サイトの利用規約の範囲（個人利用・低頻度）でお使いください。
